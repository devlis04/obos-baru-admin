# Admin Obos baru (Flutter web)

Lokal:

```
cd admin
flutter run -d chrome
```

`assets/.env` tidak di-git. Salin dari `.env.example`, isi `SUPABASE_URL` dan `SUPABASE_ANON_KEY`.

Situs komputer lain (setelah GitHub Pages nyala):

https://devlis04.github.io/obos-baru-admin/

Push ke `main` membangun web otomatis. Repo lama `obos-admin` tidak diubah.
